# YouTube Clone — HTML & CSS Course (SuperSimpleDev)

A YouTube homepage clone built while completing SuperSimpleDev's HTML & CSS course. I've finished the full course and earned the certification.

## What's included

- `html-css-course/youtube.html` — the main YouTube homepage clone (header, sidebar, video grid)
- `html-css-course/flexbox.html` — Flexbox practice
- `html-css-course/grid.html` — CSS Grid practice
- `html-css-course/position.html` — CSS positioning practice
- `html-css-course/intro-to-html/` — early HTML fundamentals exercises
- `html-css-course/styles/` — stylesheets for the YouTube clone
- `html-css-course/icons/`, `html-css-course/thumbnails/`, `html-css-course/channel-pictures/` — assets used in the clone

## Skills practiced

- Semantic HTML structure
- CSS Flexbox and Grid layouts
- Responsive design
- Positioning and general styling fundamentals
